# Dikta v1.5.8 — Reliable Voice Downloads

Native Read Aloud setup now accepts the exact Hugging Face CDN host used by the publicly pinned voice assets, so setup can complete when Hugging Face redirects a download to `us.aws.cdn.hf.co`.

The redirect policy remains deliberately narrow: it still requires HTTPS, no explicit port, and an exact allowlisted host. Downloaded files still must match their pinned size and SHA-256 digest before they are installed.

Dikta v1.5.8 requires macOS 15 or later. Read Aloud remains unavailable on macOS 26.4–26.5.
