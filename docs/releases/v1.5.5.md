# Dikta v1.5.5 — Read Aloud, Simplified

Read Aloud is now simpler to set up and use. One-time native Kokoro setup downloads and verifies the base model and English frontend, then stages four bundled, verified voices: Heart (`af_heart`), Nicole (`af_nicole`), Adam (`am_adam`), and George (`bm_george`). Synthesis is fully offline after setup.

The optional voice-download controls have been removed. If an earlier setup has only Heart alongside an intact base installation, upgrading stages the remaining bundled voices locally without another base fetch.

Choose a reading speed in Advanced: Slow (0.75×), Normal (1×), Fast (1.25×), or Speedy (1.75×). The chosen voice and speed are captured when a read begins, including for progressive reading, so changes made while it is speaking apply to the next request.

Dikta v1.5.5 requires macOS 15 or later.

**Known limitation:** native Read Aloud is unavailable on macOS 26.4–26.5; update macOS to use it. Other Dikta features are unaffected by this Read Aloud guard.
