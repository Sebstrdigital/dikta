# Dikta v1.5.9 — Reliable Push-to-Talk

Push-to-talk now handles hotkey releases received while the microphone is still starting, instead of losing the stop request. Repeated presses during startup no longer start overlapping recordings.

Holding an extra modifier no longer cuts a push-to-talk hold short. Custom key-plus-modifier shortcuts also stop correctly when the modifier is released before the regular key. Press-to-start/press-to-stop recording remains unchanged.

The stray M in Slack was caused by Dikta's automatic Slack microphone muter sending a bare keystroke into the active window. That unsafe behavior has been removed. **Automatic Slack muting is disabled; mute Slack manually during Huddles when needed.**

Dikta v1.5.9 requires macOS 15 or later. Read Aloud remains unavailable on macOS 26.4–26.5.
