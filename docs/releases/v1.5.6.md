# Dikta v1.5.6 — Faster Read Aloud

Read Aloud now responds immediately with visible preparation feedback while it selects text, checks assets and generates speech. You can press the Read Aloud hotkey again to cancel during selection or preparation, as well as during playback.

Medium selections with a short opening sentence can start speaking sooner. The complete selection is still read, with the existing bounded generation and playback pipeline. Short, unsentenced and long selections retain their previous chunk planning.

Cancelled or stale reads cannot interfere with newer requests. Content-free, request-correlated timing also makes future onset delays easier to diagnose; timing logs do not include the selected text. Playback scheduling is reported separately from physical audible output.

Dikta v1.5.6 requires macOS 15 or later. Reading remains offline after the one-time native Kokoro setup.

**Known limitations:** native Read Aloud is unavailable on macOS 26.4–26.5; update macOS to use it. Cold-start latency varies, and this release does not claim that every previously reported long first-read delay is resolved.
