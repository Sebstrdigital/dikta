# Dikta v1.5.4 — Simpler Dictation

Dikta now offers one simpler transcription experience. Parakeet Ultra handles dictation, imported audio, microphone Debrief, and call Debrief, so there is no longer an engine, model, or language picker to manage. The language-switch hotkey has also been removed.

Ultra determines the spoken language automatically from audio, without a manual language hint. Once text exists, Format Selection and Debrief infer their language-dependent behavior from that actual text rather than from an old preference.

Upgrading does not discard your other settings or dictation history. Legacy engine, model, language, and language-hotkey values remain readable compatibility data, and existing model caches are left in place.

Indonesian is no longer a supported transcription language. Older configurations containing Indonesian remain readable, but selecting Indonesian is no longer available.

Mixed English and Swedish transcription is best-effort and should not be treated as reliable code-switching. During qualification, short English contributions sometimes disappeared from mixed English/Swedish takes. This release does not claim improved Swedish accuracy.

Dikta v1.5.4 requires macOS 15 or later.
