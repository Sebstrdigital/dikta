# Dikta for Omarchy feature checklist

This tracks Omarchy/Hyprland functionality separately from the macOS and Windows apps.
A checked item is implemented; unchecked items are future possibilities, not promises.

## Dictation

- [x] Start and stop dictation with a global shortcut
- [x] Offline transcription with Parakeet Ultra
- [x] Paste into the focused application, or copy if focus changes
- [x] Keep and copy the five most recent dictations
- [x] Configurable dictation shortcut
- [x] Start and stop sound feedback
- [x] Theme-matched Omarchy bar panel with history, hotkey settings, About, and notification toggle
- [x] Optional desktop notifications, disabled by default
- [x] Start in the background at login
- [ ] Push-to-talk
- [ ] Configurable microphone
- [ ] Silence auto-stop
- [ ] Separate persistent recording indicator

## Other macOS features

- [ ] Format selected text
- [ ] Read selected text aloud
- [ ] Microphone debrief and imported-audio transcription
- [ ] Call debrief with microphone and system audio
- [ ] Automatic microphone muting in call apps

## Linux integration

- [ ] Install as an Arch package
- [ ] Translated interface and live Omarchy language changes
- [ ] Support desktop environments beyond Hyprland
